sudo gvm-start
```

Service status and configuration correct ah iruka nu verify panna:

sudo gvm-check-setup
```
*(Setup check la ella checks um `OK` nu varanum)*.

*(Oru vela lab machine la **Nessus** iruntha: `sudo systemctl start nessusd` run pannanum)*.

#### Step 4: Scan Task Create Panni Run Panradhu
1. OpenVAS menu la **Scans** -> **Tasks** click pannanum[cite: 3].
2. **New Task** select panni:
   * **Task Name:** `Lab Vulnerability Scan`
   * **Scan Targets:** Step 3 la create panna target ah select pannanum[cite: 3].
   * **Scan Config:** **`Full and Fast`** select pannanum[cite: 3].
3. **Save** pannitu, play button (Start) click panna scan run aaga aarambikum[cite: 3].

### Key Findings & Remediations (Lab Record / Report ku)

Manual la ethavathu **2-3 key findings mariyum remediations** document panna sollirukaanga[cite: 3]. Metasploitable2 scan panna regular ah kedaikira findings:

1. **vsftpd 2.3.4 Backdoor (Port 21)**
   * **Severity:** Critical (CVSS 10.0)[cite: 3]
   * **CVE:** CVE-2011-2523[cite: 3]
   * **Remediation:** Outdated vsftpd package ah latest patched version ku update pannanum[cite: 3].

2. **UnrealIRCd Backdoor Execution (Port 6667)**
   * **Severity:** Critical[cite: 3]
   * **CVE:** CVE-2010-2075[cite: 3]
   * **Remediation:** Vulnerable Unreal3.2-beta binary ah safe clean version vechu replace pannanum[cite: 3].

3. **Weak / Default SSH Credentials (Port 22)**
   * **Severity:** High[cite: 3]
   * **Remediation:** Default passwords disable panni, SSH Key-based authentication enforce pannanum[cite: 3].
